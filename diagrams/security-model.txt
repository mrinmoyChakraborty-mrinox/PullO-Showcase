║  ATTACK SURFACE ANALYSIS                                 ║
╚══════════════════════════════════════════════════════════╝

  ┌────────────────────────────────────────────────────────┐
  │  What an attacker CAN see:                             │
  │    • PullO Cloud API (rate-limited, authenticated)    │
  │    • Your public IP? No — they see PullO's servers    │
  │                                                       │
  │  What an attacker CAN'T see:                          │
  │    • Your machine's IP                               │
  │    • Your local network                              │
  │    • Your running models                             │
  │    • Your prompts (not stored anywhere)               │
  │    • Your API keys (hashed at rest, TLS in transit)   │
  │    • Your Ollama endpoint (localhost, unreachable)    │
  │                                                       │
  │  What if they steal an API key?                      │
  │    • Scoped to specific model(s)                      │
  │    • Rate limited (configurable RPM + daily budget)   │
  │    • Revocable from dashboard in one click            │
  │    • Logged — you'll know exactly what was used       │
  └────────────────────────────────────────────────────────┘

╔══════════════════════════════════════════════════════════╗
║  PRIVACY GUARANTEES (the short version)                  ║
╚══════════════════════════════════════════════════════════╝

  ✓ Prompts are NEVER written to disk on PullO servers
  ✓ Models NEVER leave your machine
  ✓ Request metadata (tokens used, model name, latency)
    is logged for analytics — NOT the content
  ✓ Your machine's IP is NEVER exposed to API callers
  ✓ No inbound ports. Ever. Period.
  ✓ No data stored = nothing to leak in a breach
