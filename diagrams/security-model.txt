SECURITY PROPERTIES:
  ✓ No public IP required
  ✓ No open inbound ports
  ✓ Works behind NAT / corporate proxy
  ✓ API key authentication (SHA-256 hashed)
  ✓ Per-model access scoping
  ✓ Rate limiting per key (RPM + daily budget)
  ✓ Prompts never persisted to disk
  ✓ mTLS between extension and cloud relay
