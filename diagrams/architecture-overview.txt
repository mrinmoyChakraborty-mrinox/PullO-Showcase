╔══════════════════════════════════════════════════════════╗
║  THE CORE INSIGHT (say it loud for the people in back)   ║
╚══════════════════════════════════════════════════════════╝

  Instead of PUSHING traffic into your machine (open ports,
  firewall holes, praying to the networking gods)…

  …PullO's extension PULLS requests from a cloud queue over
  a single outbound connection. Like checking your email
  instead of leaving your door unlocked.

  ┌─────────────────────────────────────────────────────┐
  │  ✓ Zero inbound ports    ✓ Works behind any NAT     │
  │  ✓ No public IP needed   ✓ No DevOps degree required│
  │  ✓ Corporate firewall?    ¯\_(ツ)_/¯  Still works.    │
  └─────────────────────────────────────────────────────┘


╔══════════════════════════════════════════════════════════╗
║  PRODUCT LINGO (for pitch decks and hackathon judges)    ║
╚══════════════════════════════════════════════════════════╝

  Connection model   → Outbound WebSocket polling (pull)
  Machine exposure   → Zero inbound ports; you're invisible
  Auth               → Scoped API keys per workspace/model
  Team sharing       → Role-based workspaces (Owner/Admin/Member)
  Usage tracking     → Per-request analytics + token counts
  Provider support   → Ollama, LM Studio, llama.cpp, any /v1
  Streaming          → Native SSE from model → client
  Privacy            → Prompts never stored. Ever.
  Overhead           → ~20-80ms — you won't notice it


╔══════════════════════════════════════════════════════════╗
║  WHAT THIS IS NOT                                         ║
╚══════════════════════════════════════════════════════════╝

  ✗ NOT a cloud inference provider (we don't run models)
  ✗ NOT a VPN (your machine isn't on a virtual network)
  ✗ NOT a tunnel (there's nothing to tunnel TO)
  ✗ NOT magic (just a well-designed WebSocket relay)

  It's a private AI network layer. Nothing more, nothing less.
