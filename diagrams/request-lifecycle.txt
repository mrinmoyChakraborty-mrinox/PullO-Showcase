╔══════════════════════════════════════════════════════════╗
║  THE NUMBERS (latency breakdown)                         ║
╚══════════════════════════════════════════════════════════╝

  ┌──────────────────────────────────────────────────────┐
  │  Step                   │  Typical                   │
  ├──────────────────────────────────────────────────────┤
  │  Client → Cloud         │  ~5-20ms  (network)       │
  │  Cloud → Extension      │  ~1-5ms   (WebSocket push)│
  │  Extension → Ollama     │  ~1ms     (localhost)     │
  │  Model inference        │  ~500ms+  (you know this) │
  │  Response streaming     │  real-time, same path back│
  │                         │                           │
  │  TOTAL OVERHEAD         │  ~20-80ms                 │
  │  (without inference)    │  ─ barely measurable      │
  └──────────────────────────────────────────────────────┘

  Translation: Your model's response time is dominated by
  the model itself. The relay overhead is a rounding error.


╔══════════════════════════════════════════════════════════╗
║  WHAT COULD GO WRONG                                     ║
╚══════════════════════════════════════════════════════════╝

  ┌──────────────────────────────────────────────────────┐
  │  Extension offline?     → Request queues for 30s    │
  │                          → Then 503 Service Unavail │
  │                          → Clean failure, no fraud  │
  ├──────────────────────────────────────────────────────┤
  │  Model crashes mid-     → Error forwarded verbatim  │
  │  request?               → Client sees the Ollama    │
  │                          error, just like direct    │
  ├──────────────────────────────────────────────────────┤
  │  Chrome suspended?      → Extension reconnects on   │
  │                          wake → picks up where it   │
  │                          left off                   │
  └──────────────────────────────────────────────────────┘
