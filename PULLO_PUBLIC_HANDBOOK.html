What is PullO?

PullO is a private AI runtime layer that connects your locally-running models to your team through a secure cloud gateway. Think of it as a reverse proxy for your local AI infrastructure — purpose-built for teams that care about data privacy and latency.

🔒

Privacy by Design

Your prompts and model weights never leave your machine. The cloud only relays messages — we never store your data. Enterprise-grade security without the enterprise overhead.

🔌

Drop-in OpenAI Replacement

Works with any OpenAI-compatible client. Just change the base URL and API key. Use your existing tools, SDKs, and frameworks — no code changes needed.

👥

Team Access Controls

Invite teammates, assign roles (owner, admin, member), create scoped API keys with per-model permissions and daily budgets. Full workspace isolation.

⚡

Built-in Intelligence Layer

Web search, URL fetching, and custom tool integrations via webhooks. Extend your models with MCP (Model Context Protocol) and Corsair plugin marketplace.

📊

Real-time Analytics

Monitor request volumes, latency, error rates, and token usage across your workspace. Export logs, track trends, and keep your team accountable.

🌐

Works Everywhere

Behind corporate firewalls, on VPNs, in air-gapped environments. If your machine can reach the internet, your team can reach your models.

Get started in 5 minutes

1

Install Ollama

Download and run Ollama on your machine. Pull any open-source model — Llama 3, Mistral, DeepSeek, CodeGemma, or your own fine-tuned models.

2

Install PullO Desktop Agent

Install the PullO Chrome Extension. Log in with your account, and it automatically discovers your local Ollama instances.

3

Create API Keys

In the PullO dashboard, generate API keys for your team. Set rate limits, model access, and daily budgets. Share keys instantly.

4

Start Building

Use any OpenAI-compatible client with your new endpoint. Build AI features, automate workflows, or create internal tools — all powered by your local hardware.
